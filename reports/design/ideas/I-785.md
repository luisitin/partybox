Branch `b/I-785-C` cherry-picked cleanly, plus:

- The join form's example name ("e.g. Sam") read the first listed room's names, which C no longer
  sends without a code — so a phone that scanned a QR lost it. It now reads the names of the room

  `/api/funnel` now leave out.
