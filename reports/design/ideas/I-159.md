# I-159 · shipped option B (Blanks: big type reads the hand as a list, plus a Fan / List switch)

Cherry-picked `b/I-159-B` (09fdb3b1) onto session-c. The branch predates I-160 B (sideways list),
which main already had; the two share `useHandList`, so the merge keeps both triggers — the list
shows when the phone is on its side (I-160) OR the type is so big the hand is under 15 card-type
widths across (I-159 A) — and the phone's own Fan / List choice (B, `localStorage pb.blanks.hand`)
overrides both. The sideways split layout (`handSplit`) stays.
