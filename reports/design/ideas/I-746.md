# I-746 · engine + TV · a room whose phones all went to sleep — shipped option C

Cherry-picked `b/I-746-C` (55ab88bf) cleanly: during a game a quiet seat is kept (A, plus the
VIP-handover busy loop fix), the last phone dropping pauses the game with `asleep: true` in the
snapshot and a TV banner, the first phone back resumes it (B), and 5 minutes with nobody back ends
the game to the lobby (C). `asleep.test.ts` covers each.

On top of the branch:

- **Spanish**: the banner, its small line and the paused card's hint are `t.tv.asleep*` in
  i18n-en/es; the toast "Nobody came back — the game ended." is in server-text's table. The banner
  moved to `tv/AsleepBanner.tsx` (TvApp stays small).
- **Flag hygiene**: `awakeOutsideGames` (room.ts) drops `asleepSince` whenever the room is not
  playing — the branch cleared it only on a wake or the 5-minute valve, so a game ended another way
  while asleep (the TV's Home) would have left the flag set and the next game would have been ended
  by the valve at once.
- **A VIP pause survives**: if the VIP had paused before everyone dropped, the wake no longer
  resumes it (`asleepKeptPause`). Two tests added (6 in the file).
- Documented in docs/PROTOCOL.md ("Everyone asleep") and the Bingo README.
