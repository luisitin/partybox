# I-021 · Broken Pencil's pad feels like paper and pencil — option C, as options (shipped)

Spec: `C:\dev\partybox-ideas\specs\I-021.md` (the owner's pick, branch `b/I-021-C`, with the
owner's note: the background and pencil style must be optional). Built as the spec's note asks:

- `packages/game-sdk/src/ui/pad.ts` — `getPadStyle` / `setPadStyle` / `usePadStyle`, per device in
  localStorage (`partybox:pad`), the motion switch's pattern; default `{ paper: 'ruled', pencil:
'pencil' }` (the owner's pick). It lives in the game-sdk, not `packages/client`, because a game may
  import only `@partybox/game-sdk` (ADR-009) — the spec's `pad.ts` next to `theme.ts` would have been
  unreachable from the pad.
- The phone's settings sheet (`PhoneSettings.tsx`, the theme sheet's footer) has two new rows:
  Drawing paper (Ruled / Plain) and Drawing pencil (Pencil / Pen), each one tap.
- `paint(ctx, strokes, size, style)` takes the style; its default is plain paper + pen, the line
  every screen has always drawn. Only the DrawPad passes the phone's style; the stored stroke data
  and the TV's SVG are untouched either way. The deal-in (sheet + swatches) always plays.
