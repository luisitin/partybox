# I-077 · The lobby counts the phones that never made it in (option C)

Branch `b/I-077-C` reapplied by hand on the current files (the branch predated I-034's `lastRecap`,
I-041's `qrUrl` and I-071's ★ pill, so `info.ts`, `HostBar.tsx` and `app.ts` conflicted; `funnel.ts`
and `sockets.ts` applied unchanged).

## What ships

- **A** — a per-room funnel in memory: `opened` (join-page `/api/info?from=phone` fetches),
  `attempted` (join messages), `joined` (welcomes), `failed` by error code. `GET /api/funnel`.
- **B** — `<recordings>/funnel/<room>.json`, rewritten on change, only when the process keeps
  recordings (ADR-035). Writes are queued so they never race.
- **C** — live on the TV's host bar, polled every 5 s: "4 opened · 1 in".

Counts only — no names, no ids. "Opened" counts info fetches from a surface carrying
`data-surface="controller"` (about two per page load), so it is an upper bound, not a head count;
the TV and `/preview` stay uncounted.
