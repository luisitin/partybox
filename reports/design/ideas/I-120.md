# I-120 · The lobby leaves behind a curtain, not a ghost (option B)

Branch `b/I-120-B` cherry-picked clean — `CrossfadeSwap.tsx` / `.module.css` and `tv/TvApp.tsx`.

## What ships

- **A** — a `curtain` prop on `CrossfadeSwap`, set by the TV for lobby → playing: the held snapshot of
  the lobby is washed to the background colour over `--pb-motion-base`, THEN fades, so the intro lands
  on an empty stage. Any game's first phase gets it.
- **B** — while it darkens the snapshot slides left 6 % and shrinks to 98 %: cleared away, not dissolved.

Reduced motion (the OS setting or PartyBox's own motion switch) never makes a snapshot at all — the
same path as the existing fade — so there is nothing to animate there.

## Proof

Scratchpad `c-capture/probe_I120.ts` samples the outgoing snapshot on the real TV every animation
frame from the start of a Bingo game (the host holds it until the game's first frame is ready):

```
  74 ms  curtain=true  opacity 1.00  wash 0.00                           ← held while the game loads
1561 ms  released
1586 ms               opacity 1.00  wash 0.22  translateX  -25.9  scale 1.00
1655 ms               opacity 1.00  wash 0.80  translateX  -92.6  scale 0.98
1858 ms               opacity 1.00  wash 1.00  translateX -115.2  scale 0.98   ← dark, 6 % of 1920 px
1903 ms               opacity 0.56
2110 ms               opacity 0.00                                         ← then gone
```

Two beats, in order — dark and cleared away first, then gone — at the base token. `pnpm verify` GREEN.
