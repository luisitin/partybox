# I-753 · lobby · the developer controls locked to the host PC — shipped option C

Branch `b/I-753-C` cherry-picked cleanly, plus:

- **Tunnel hardening**: a request the Cloudflare quick tunnel (Share) relays also arrives from
  127.0.0.1, which the branch's loopback check would have treated as the host PC — so anyone with
  the Share link could have used the developer API. A request carrying `cf-connecting-ip` or
  `x-forwarded-for` is now not the host PC (403).
- Two more tests: the tunnel-relayed request gets 403, and a socket with `Origin:
http://evil.example` is refused while one from the server's own host connects.
- `docs/DEV_API.md` and the server README say so.
