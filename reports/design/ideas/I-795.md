# I-795 · broken-pencil · design review I: on a guess, the box to type in is always on screen — shipped

No Session B branch existed (`b/I-795-A` absent), so this was built from the review's drawn after
(`specs/design-review-f4f43d17/phone-screens-redrawn.html#I`).

- SDK `TextAnswer` gained an optional `lead`: shown above the prompt and given whatever height
  the prompt, a one-line field (it grows with its text via `field-sizing`) and the button leave;
  with a lead the 0/40 counter is left out, as in the mock-up. Other games' TextAnswer screens are
  unchanged (Wisecrack re-checked on the SE and at 200 % text: 3-row field, counter, full timer bar).
- Broken Pencil's guess passes the drawing as the lead, square and as large as that box allows
  (`min(100cqw, 100cqh)`), seated on the question. A tap opens it over the whole phone (blurred
  scrim); a tap or Escape puts it back. Prompt "Last guess: what is this?" as drawn (Spanish was
  already "Última respuesta: ¿qué es esto?").
- Keyboard: `useKeyboardInset` reads `visualViewport` (iOS Safari and Chrome shrink only the visual
  viewport); the guess Screen pads its bottom by the covered height, the drawing yields (to nothing
  on an SE) and the prompt drops to body size, so the field and Send sit above the keys. A browser
  that resizes the layout viewport gets the same through plain flex.
