# I-089 · The disconnect grace counts down where you can see it (option C)

Branch `b/I-089-C` reapplied; four of the five files conflicted (I-070's wave on `PlayerChip`,
I-071/I-072 on `TvLobby` and `PlayerChips`) and every conflict kept both sides. One CSS block had to
be closed by hand where the two sides met mid-rule.

## What ships

- **A** — the TV counts the 120 s grace down after a dropped player's name ("1:58"), from the first
  tick that sees them offline, through an `awayLeft` map into `PlayerChips`.
- **B** — a thin ring drains around the dimmed face (a conic gradient on `--pb-away`).
- **C** — the dropped phone's own banner says how long: "Reconnecting… 1:47 left".

Both countdown hooks were rewritten in the repo's existing shape (`HostBar`'s `useVipAway`): the
interval owns the state, so render reads no ref and calls no clock. The branch kept its timestamps
in refs, which this repo's react-hooks rules reject. The phone's hook now lives in
`controller/grace.ts` (`useGraceLeft`), which also kept `ControllerShell` under the 300-line cap.
