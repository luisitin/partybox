# I-146 · Blanks · the final board reads straight down — shipped option C

Branch `b/I-146-C` applied (`TvResult.tsx` dense from 7 rows; `Scoreboard` band + tie bracket).
Conflict in `Scoreboard.tsx` resolved keeping main's translated rank label (`L('rank {rank}')`)
beside the branch's band.

Fixes on top of the branch (behaviour kept, bugs removed):

- **A bracket never crosses a column break.** The 8-player probe showed the branch's bracket for a
  rank-4 tie dangling ~60 px off the foot of column 1 (its last row opened the tie) and an
  uncapped bar running down the gap before column 2. `tieEdges()` now closes a tie at each column
  break, so each column gets its own capped bracket.
- **No bracket on a `noRanks` board** (I-128: an all-zero board has nothing to rank; the branch
  would have bracketed every row).
- The two helpers are exported pure functions (`tieEdges`, `rankBand`) with unit tests
  (`Scoreboard.test.ts`, 3 new cases). DESIGN_SYSTEM.md names both behaviours.

Note: the bracket and band live in the SDK `Scoreboard`, so every game's split/tied board (and the
shell's results list on phones) now shows them — as the branch built it.
