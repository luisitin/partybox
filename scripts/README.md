# scripts/

Cross-platform maintenance scripts, run with `tsx` (no build step). Each is a `pnpm` script.

| Script                   | Command                                                                                         | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------------ | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `verify.ts`              | `pnpm verify`                                                                                   | the commit gate: registry → typecheck → lint → deps → format → tests → sim smoke → build → bundle → drift                                                                                                                                                                                                                                                                                                                                                     |
| `check-bundle.ts`        | `pnpm check-bundle [--update]`                                                                  | builds the client in memory (its own Vite and config) and reads the output bundle, never a manifest. Fails when the entry chunk carries more `games/*` modules than the ratchet, the entry's gzip grew over 1 KB, a game's phone closure (its chunks + static imports + their CSS, JS + CSS gzip) is over budget, or a manifest would ship; prints each game's phone/TV gzip and any `Tv*` module riding on a phone. `--update` rewrites `bundle-budget.json` |
| `bundle-budget.json`     | —                                                                                               | what `check-bundle` holds the build to, in bytes (KB = 1024): `entryGameModules` (ratchet, F1 drives it to 0), `phoneBudgetGzip`, `entryGzip`                                                                                                                                                                                                                                                                                                                 |
| `gen-registry.ts`        | `pnpm gen-registry [--check]`                                                                   | write/verify `packages/{server,client}/src/games.generated.ts`                                                                                                                                                                                                                                                                                                                                                                                                |
| `check-drift.ts`         | `pnpm check-drift`                                                                              | docs/registry/fixtures/TODO/dependency drift checks                                                                                                                                                                                                                                                                                                                                                                                                           |
| `new-game.ts`            | `pnpm new-game <id>`                                                                            | copy `games/_template` → `games/<id>`, rewrite ids, regenerate registry                                                                                                                                                                                                                                                                                                                                                                                       |
| `lan-ip.ts`              | `pnpm lan-ip`                                                                                   | print the LAN IPv4 the server will advertise                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `resolve-loop-log.ts`    | `pnpm resolve-loop-log`                                                                         | resolve a `reports/design/loop-log.md` merge conflict: rows are identified by text, main's order kept, HEAD's new rows appended; a number two games share is renumbered past the top (the later row), never dropped                                                                                                                                                                                                                                           |
| `blanks-fit-report.ts`   | `pnpm blanks-fit-report [--decks wild-only] [--players 6] [--runs 30] [--sample N] [--md file]` | the Blanks fit report: what the deck's black cards ask for and what its whites serve, then simulated games replayed to measure every hand (cards serving the round's slot, tier-3 cards) and the bots' plays                                                                                                                                                                                                                                                  |
| `blanks-kinds.ts`        | `pnpm blanks-kinds [--since main] [--all]`                                                      | the kind the fit model reads into every card added since a revision (a prompt's blank: thing / doing / person / name:word / name:line; a white's serves) — the check on a batch of new content before it plays                                                                                                                                                                                                                                                |
| `blanks-kinds-golden.ts` | `pnpm blanks-kinds-golden`                                                                      | regenerates `games/blanks/__tests__/kinds.golden.json`, the prompt and card kind reads the fit loop verified by hand (kinds.test.ts pins them): run after a deliberate rule change, read the diff, commit both                                                                                                                                                                                                                                                |
| `lib/games.ts`           | —                                                                                               | game folder discovery + `REQUIRED_GAME_FILES` (single source of truth)                                                                                                                                                                                                                                                                                                                                                                                        |
| `lib/run.ts`             | —                                                                                               | tiny process runner                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `lib/bundle.ts`          | —                                                                                               | the pure half of `check-bundle`: game modules in the entry, surface chunks (`phone.ts`/`tv.ts` or `Controller.tsx`/`Tv.tsx`), the static-import closure, gzip                                                                                                                                                                                                                                                                                                 |

Rules: no runtime code here (the server must not import scripts); keep each script single-purpose;
Windows and POSIX must both work (use `node:path`, `shell: true` for pnpm).
